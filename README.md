# ポケモン対戦ログ (Battle Log App)

ポケモンの対戦結果・選出・メモ・反省点を簡単に記録し、振り返りやデータ分析（勝率・選出率）ができる軽量なWebアプリケーションです。  
Google Apps Script (GAS) と連動し、データおよび選出画面のスクリーンショットをGoogleスプレッドシート／Googleドライブへ自動保存します。

---

## 📱 主な機能

### 1. 📝 対戦記録（Record）
* **選出画面のスクショ保存**: 選出画面のスクリーンショット画像を自動で圧縮・Base64化し、Googleドライブへ保存。
* **シングル / ダブル対応**: モード切り替えにより、自分の選出枠（3体 / 4体）が動的に変化。
* **選出ポケモンの入力**:
  * 自分の選出ポケモン（1〜3/4体目）
  * 相手の見えたポケモン（1〜6体目）
* **試合情報の記録**: 対戦相手名、勝敗（勝ち/負け/引き分け）、天候・戦術（雨/晴れ/砂嵐/雪/トリルなど）。
* **攻防メモ & 反省点**: 印象に残ったターンや選択ミス、次回の改善点をテキスト保存。

### 2. 📖 振り返り（Review）
* **カード型UI**: 1試合ごとにスクショ付きで読みやすく表示。
* **ソート機能**: 「新しい順」と「ランダム（ランダム復習）」を切り替え可能。
* **ページネーション**: 直感的に過去の対戦へアクセス。

### 3. 📊 スタッツ（Stats / 分析）
* **勝率可視化**: 全体勝率および直近10戦の勝率をバーグラフで表示。
* **ランキング表示**:
  * 自分の選出率 トップ6
  * 相手の選出率 トップ6
  * 相手の先発率 トップ6

## 🛠 使用技術

* **フロントエンド**: HTML5, CSS3, JavaScript (ES6+, Vanilla JS)
  * ダークモード風のモバイルファーストデザイン
  * UIライブラリ非依存（軽量・高速動作）
  * Canvas API（画像圧縮処理）
* **バックエンド**: Google Apps Script (GAS)
* **データベース・ストレージ**:
  * Google スプレッドシート（対戦データの保存）
  * Google ドライブ（選出画像の保存）

## 🚀 導入・セットアップ手順

### 1. Google Apps Script (GAS) の準備

1. 新しい **Google スプレッドシート** を作成します。
2. メニューの `拡張機能` > `Apps Script` を開きます。
3. POST/GETリクエストを受け取るスクリプトを記述します。
   - **`doPost(e)`**: 送信された対戦ログを受け取り、スプレッドシートに追記＋画像をGoogleドライブに保存してURLを発行。
   - **`doGet(e)`**: `action=list&mode=single` などのクエリを受け取り、該当モードの過去ログ一覧をJSONで返却。
4. `デプロイ` > `新しいデプロイ` を選択。
   - **種類**: Web アプリ
   - **アクセスできるユーザー**: 全員 (`Anyone`)
5. 発行された **ウェブアプリのURL** をコピーします。
